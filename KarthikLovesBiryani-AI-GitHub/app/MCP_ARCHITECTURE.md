# Tool adapter and MCP status

The Integrations view lists local simulated tools for reviews, orders, menu/costs, inventory, reporting, and approvals. Agent requests append tool names and operation summaries to an in-memory trace. Recommendation decisions are stored in browser local storage.

No protocol-level Model Context Protocol server or client is implemented. No connection to Swiggy, Zomato, Google, WhatsApp, a POS, or an inventory provider exists. This distinction is shown in the interface.
