# Five-act demonstration guide

1. **The pain:** Overview displays 4.3 historical and 3.8 current, then inspect complaint categories and sample reviews.
2. **The agent arrives:** Open AI Agent and ask, “Why are customers complaining about Chicken Dum Biryani?” Point out retrieved review and document IDs and the simulated tool trace.
3. **Under the hood:** Show Knowledge Base term retrieval and Integrations. Explain that lexical retrieval is real in this demo, while the adapters are simulated and are not protocol-level MCP.
4. **Something goes wrong:** In Demo mode, show the deliberate soggy-rice misclassification scenario and save the owner's corrected label. The source record remains unchanged.
5. **The new normal:** Compare the 3.8 current cohort with the 4.1 simulated-after cohort. State that both are synthetic and the comparison does not establish an intervention effect.

Use **Reset demo data** to clear owner decisions and the correction between runs.
